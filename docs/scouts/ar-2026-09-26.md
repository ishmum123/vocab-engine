Gotchas: MSA vs dialect (kaikki ar scope + CAMeL dialect ID); clitics (و/ف/ب/ل, pronoun suffixes) → lemma via analyzer; strip ال- for lemma, display indefinite; normalise أ/إ/آ→ا, ة/ه, ى/ي, tatweel; unvocalised sources → display-only pron from kaikki vocalised canonical + romanization; broken plurals from kaikki forms + hand table; verb lemma = 3sg masc perfect (Wiktionary convention); RTL like Persian; typing: accept transliteration; TTS ar-SA/ar-EG and STT unverified. Letter names/romanisation for the script primer: Wiktionary "Arabic alphabet" appendix (hand table, ~30 rows).
